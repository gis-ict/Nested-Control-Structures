How to use this page

Work in your team of three: Driver, Navigator and Tracer. Swap jobs after each step.

  1. Predict first. Agree on your answer before you click or run.
  2. Run to check. Click Run under any program. Change the code and run it again.
  3. Explain. Say why the answer is correct in one sentence.
  4. Mark the step as done when your team finishes it.

When a program uses input(), a box pops up. Type your answer there and click OK. You can also type all your answers in Inputs (one per line) before you click Run.

If the program does not stop, the runner stops it for you after a few seconds.

The code runner loads Python from the internet the first time a student clicks Run (about 10 to 30 seconds). After that it is instant. If the school network blocks it, students can copy the code with the Copy button and paste it into VS Code. Click "Teacher notes: on" in the top bar to show these notes when you project the page.

What is a nested control structure?

10 minutesWhole class

A control structure controls which lines run and how many times. In Python they are if, for and while.

A control structure is nested when it is inside another control structure.

The indentation shows the nesting. Each extra 4 spaces is one nesting level deeper.

LevelIndentationWhere it is
00 spacesThe main program
14 spacesInside one control structure
28 spacesInside two control structures
312 spacesInside three control structures

You already wrote nested code in Activity 4. The if is inside the while loop.

while guess != secret: Level 0: the while loop
if guess < secret: Level 1: selection inside the loop
print("Too low") Level 2: runs only when the loop is running AND the guess is too low

Check Count the nesting levels

Ask students to point at the indentation on their own screens. A useful line: "The more spaces, the deeper inside it is. Python only reaches a deep line if every condition above it lets it in."

Two kinds of nesting

15 minutesTeams of threeRun each program

A. Selection inside a loop

The loop repeats. Each time round, the if makes a choice.

B. A loop inside selection

The if makes a choice. The loop runs only if the condition is True.

Plan it: pseudocode and a flowchart

15 minutesTracer writes on paper

The plan: a guessing game with lives

The player has 3 lives. Each wrong guess gives a hint (too low or too high) and takes away one life. The game ends when the player guesses correctly or has no lives left.

Team task
  1. Read the pseudocode. Cover the Level column with your hand and say the level of each line.
  2. Find each line of the pseudocode on the flowchart.
  3. The Tracer copies the pseudocode onto paper and marks the nesting levels.

Pseudocode with nesting levels marked

LevelPseudocode
0Set secret to 7, guess to 0, attempts to 0, lives to 3
0WHILE guess is not secret AND lives is more than 0
1    Ask for a guess. Add 1 to attempts
1    IF guess is secret
2        Print "Correct!" and the number of attempts
1    ELSE
2        Take 1 away from lives
2        IF guess is less than secret
3            Print "Too low"
2        ELSE
3            Print "Too high"
2        Print the lives left
0IF lives is 0, print "Game over" and the secret number

Flowchart

The diamonds are decisions. The arrow that goes back up is the loop.

End of Meeting 1: collect the papers with the annotated pseudocode. In Meeting 2, students turn this plan into code in Step 6.
