Nested control structures

Key words

if, for and while are control structures. They control which lines run, and how many times.

Nested means one inside another. So a nested control structure is one of them inside another one.

Think of it like a small box inside a bigger box.

In Scratch, you could see the nesting

when green flag clicked forever
if touching Player? then
say Caught you!

You can see the if block sitting inside the forever block.

In Python, indentation shows the nesting

Example only: touching_player is not a real Python word. It just matches the Scratch block.

Python has no C shapes. It uses spaces instead. More spaces = deeper inside.
4 spaces = level 1 · 8 spaces = level 2

Selection and iteration, nested

Key words

There are two ways to nest. Predict first, then click Run to check.

A. Selection inside iteration

(an if inside a loop)

The loop repeats. Each time round, the if asks a question and makes a choice.

Think of it like a teacher marking tests: for each test, if the score is 50 or more, write Pass.

B. Iteration inside selection

(a loop inside an if)

The if asks a question first. The loop only runs if the answer is True.

Think of it like this: if it rains, close every window. If it does not rain, close none.
